# Fontes locais

Space Grotesk (títulos) e DM Sans (textos) estão declaradas como famílias
tipográficas no CSS, com fontes genéricas de fallback. Quando arquivos de fonte
forem adicionados, verificar e guardar as respectivas licenças nesta pasta e
declarar os arquivos locais com `@font-face` em `src/index.css`.

Não há dependência de serviços externos de fontes.
